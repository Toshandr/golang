Задача: менеджер заказов
Напиши программу, которая хранит заказы пользователей и позволяет управлять ими.

Условия:

1. Создай структуру Order:
- ID int
- UserID int
- Amount float64
- Status string
2. Создай структуру OrderManager:
- orders []Order
- nextID int
3. Реализуй методы:
Метод	Что делает
AddOrder	Добавляет заказ и возвращает его ID
GetOrder	Возвращает заказ по ID
UpdateStatus	Изменяет статус заказа
DeleteOrder	Удаляет заказ
GetUserOrders	Возвращает все заказы пользователя

4. Добавь проверки:
- Сумма заказа должна быть больше нуля.
- Статус может быть только new, paid, cancelled.
- Если заказ не найден, возвращай ошибку.
- ID должен автоматически увеличиваться.
Дополнительные условия
- Не используй глобальные переменные.
- Передавай менеджер через указатель.
- Не используй сторонние библиотеки.
- Раздели код на несколько файлов, если считаешь нужным.
Дополнительное испытание
После основной реализации попробуй:
1. Сделать GetUserOrders так, чтобы изменение возвращённого среза не меняло внутренние заказы менеджера.
2. Реализовать DeleteOrder без утечки старых ссылок в базовом массиве.
3. Написать функцию, которая возвращает замыкание — генератор ID.
